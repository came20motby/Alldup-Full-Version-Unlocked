### Core Functionality
- **Comprehensive Duplicate Search** — AllDup employs a quick duplicate file search algorithm that works with any file type, including text, video, image, or music files, ensuring thoroughness in finding duplicates.
- **Multi-Location Scanning** — Search for duplicate files across multiple folders, optical discs, or network storage units, enabling a wider range of file management.
- **Customizable Search Filters** — Users can include search filters to exclude specific file types, tailoring the search to their needs and preferences.
- **Organized Results Display** — Duplicate files are listed and organized by their respective folders, allowing users to see the context of each file easily.
- **Preview Functionality** — AllDup allows users to view a preview of files, ensuring that the contents are indeed identical before taking action.

- **Search Result Storage** — The tool allows users to store and recover search results, making it easier to manage findings over time.
- **User-Friendly Interface** — The application features an intuitive interface that simplifies the process of setting up search parameters, making it accessible for all user levels.
